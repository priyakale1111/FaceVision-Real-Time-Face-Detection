
# Real-Time Face Detection System

A real-time face detection application built using Python and OpenCV.

## Features

- Real-time face detection using a webcam
- Detection of multiple faces
- Green rectangles around detected faces
- Individual face labels
- Live face count
- FPS (Frames Per Second) counter
- Save screenshots by pressing S
- Quit the application by pressing Q

## Technologies Used

- Python
- OpenCV
- Haar Cascade Classifier

## Requirements

- Python 3.13
- Webcam
- OpenCV 4.12.0.88

## Installation

1. Clone or download this project.
2. Open a terminal in the project folder.
3. Install the required package:

   `python -m pip install -r requirements.txt`

## Run the Project

Run this command in the terminal:

`python webcam_face_detection.py`

## Keyboard Controls

- S: Save a screenshot
- Q: Quit the application

## Screenshots

Screenshots captured during execution are saved in the `screenshots` folder.
